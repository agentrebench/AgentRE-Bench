Cross-model findings

Metadata came first; behavior reconstruction lagged

Easy layer

Format and obfuscation

  • File type was nearly saturated among valid answers.
  • Models usually recognized that strings or payloads were encoded.
  • Imports, section flags, constants, and API names survived stripping.
Hard layer

Exact execution semantics

  • No model recovered the true Level 23 C2 endpoint.
  • Native API allocation/write/thread chains were frequently incomplete.
  • Keys, decoded content, and manual PE mapping details remained brittle.
Method and verification

Compiled artifacts only

Each isolated workspace contained one anonymized PE binary. Agents could use file, strings, PE metadata, disassembly, symbol inspection, hex dumps, and entropy—no source, compilation, decompiler, debugger, or dynamic execution.

Audit passed. All 120 stored answers were independently rescored; all six aggregates reconcile; the 366-file raw-result checksum ledger is complete; all 20 binary hashes, all 10 ground-truth hashes, and all 10 source hashes match; and the focused suite passes 51/51 tests. Exact key/algorithm annotations were corrected in the deterministic scorer and every stored answer was rescored—no episode was rerun for that grading correction.

Reproduce Run python3 version3/verify.py from the repository root. No LLM judge or API key is involved.

Scoring caveat: Level 23 contributes 50% of Total by design. Main is the broader measure across process-injection levels. See the full analysis for field weights, corrections, failure taxonomy, checksums, and exact reproduction commands.
