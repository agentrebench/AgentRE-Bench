Kimi K3 leads V3. Exact behavior recovery is still incomplete.

Six models completed 120 static-analysis episodes across paired stripped and unstripped Windows PE binaries.

Bottom line: AI can accelerate malware triage, but no model recovered the true C2 endpoint and several runs refused or exhausted their tool budget.

Every answer, tool transcript, score, binary, ground truth, and checksum is published for independent review.

Effect of stripping

Removing symbols lowered scores by 6.47%—not to zero.

Across 46 model/level pairs with valid answers on both variants, mean score fell from 0.6428 unstripped to 0.6012 stripped. Static PE evidence still preserved much of the behavior models needed.

Practical meaning

Useful for triage. Not a replacement for expert reverse engineering.

Models were better at identifying the shape of a program than reconstructing the exact details needed for a final incident conclusion.

Reliable signal

Format and broad behavior

Valid answers usually identified file type, obfuscation, imports, section flags, constants, and the general technique family.

Still brittle

Exact execution details

Native API chains, keys, decoded content, and manual PE-mapping steps were often incomplete or wrong.

Unsolved

True Level 23 C2

No model recovered the actual command-and-control endpoint. Exact configuration recovery still requires expert validation.

Recommended use: analyst-assisted triage, prioritization, and hypothesis generation. Do not treat an unreviewed model report as authoritative malware attribution or configuration recovery.
Method and verification

What was tested—and how to verify it.

Environment

Static, binary-only analysis

One anonymized PE per isolated workspace. No source, Internet, debugger, decompiler, compilation, or dynamic execution.

Scoring

Deterministic ground truth

No LLM judge. Terminal refusals and budget exits remain in the aggregates. Main is the broad score; Level 23 supplies the separate Bonus.

Audit

Fully reproducible

All 120 answers were rescored, all six aggregates reconciled, and the 366-file checksum ledger and artifact hashes passed verification.

Independent check: run python3 version3/verify.py from the repository root. It requires no API key or model call.
