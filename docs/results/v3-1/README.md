# AgentRE-Bench website results v3.1

Updated October 25, 2026. The public website edition is **v3.1**. Its underlying scoring contract remains **6.2.0**, rubric **v3.4**, aggregation **artifact_mean_v1**. Website naming does not change the frozen artifacts, model episodes, or scoring evidence.

GitHub Pages serves the generated files in `docs/` directly; publication does not run the Python builders. This website release contains the public score exports and page generators. Rebuilding from original episodes also requires the archived aggregate reports, saved answers, frozen scorer/rubric, and review evidence described below; those inputs are separate from the website export.

With those archived inputs available, regenerate the page and public aggregate export from the repository root:

```bash
python3 scripts/build_site_results.py
```

The builder reads the verified reports in `results/v3_4-20261025-rescore-6_2_0/`, reuses the public aggregate exporter, and renders `scripts/site_templates/results-v3-1.html`. The homepage supplies the common navigation/footer. The design comes from the live site's `homepage.css`, `minimal-pages.css`, `home.js`, and original brand lockup, verified against public source commit `654c4042bb0022b32b522769d99f76b103f5d504`. Public JSON exports only selected scores, coverage, aggregate uncertainty, per-artifact means, recorded budget settings, and report hashes.

The findings report is generated by `scripts/site_findings.py` from all 500 frozen score records and 410 valid saved answers. `findings.json` exports field means with their answer counts, point losses that reconcile to Overall, encryption component counts, and four selected answer examples with hashes and source references. Its field means average submitted answers where a field applies; they are not an additional ranking. Correct key-byte counts are separate from algorithm-dependent key credit. Scorer-unmatched claims are not treated as a measured hallucination rate.

The visible report omits the grading-review narrative, the two output-token columns, and access-route labels. Desktop/mobile leaderboards, model comparisons, and the settings table show reasoning levels without coding-plan/API badges. Complete recorded settings remain in `scores.json`; underlying evidence and scores are unchanged.

The result explorer adds compact mobile entries, native metric-help dialogs, a two-model comparison, a shaded binary score grid with variant filters, CSV downloads, and a copyable citation. `scripts/site_interactions.py` builds static defaults and selected public comparison data. All ten pairwise intervals come directly from the frozen `COMPARISON.json`, whose hash is embedded with the data. Field comparisons retain answer counts and flag different answered subsets; correct key-byte counts remain separate from algorithm-dependent key credit. Comparison and filter controls do not change the leaderboard or its denominators.

`scripts/site_templates/findings-v3-1.html` holds the 500-word findings essay. The builder checks its word count. The October 26 revision uses “we,” explains how executable reconstruction checks can support RL for cyber defense, and distinguishes the round multiplier from the round count. Its internal training example is documented separately in [training-note.json](training-note.json): the same binary-label rule gives 25/40 and 27/40 correct for an earlier SFT checkpoint and a preference-trained checkpoint with a revised analysis workflow. It is an exploratory combined change, not an isolated RL effect or a result for the five v3.1 models. The full field table and detailed findings remain below the essay in an expandable section. Both leaderboards, metric definitions, the essay, and the default Muse–Astra comparison remain usable without JavaScript. CSVs contain the five model summaries and all 100 model/artifact means; the original score and findings JSON exports are unchanged. UI validation and screenshots are in `reviews/site-v3-1-20261025/explorer/`.

Serve the `docs/` directory to review the complete website. The old `/results/v3-pe/` path redirects here; its deployed HTML is preserved at `version3/historical/website-v3-pe-live-20261025.html`. V1/V2 history, Private Evals, RL Data, Blog, Why AgentRE, and all challenge pages retain their current deployed content. Overlapping local files were backed up in `reviews/site-v3-1-20261025/local-before-live-source/` before adopting the live source.

Browser QA compares the preview's fonts, palette, header, and branding directly against the live website. It covers desktop and phone widths, all thirteen active pages, shared themes and navigation, numeric agreement with JSON, coverage-view ordering, downloads, section links, redirects, and a usable leaderboard without JavaScript. Current evidence is recorded in `reviews/site-v3-1-20261025/live-design/`; the earlier preview receipts are historical and do not validate the current design.
