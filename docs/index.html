Latest findings

October 25, 2026
  • Muse Wonder wins v3.1. It scored 87.37/100 to Astra’s 87.04, earning more credit for technique identification.
  • Astra was stronger on encryption. It received full algorithm and key credit in all 100 answers. Muse did so in 96.
  • The errors went beyond missing keys. Models omitted cipher details, confused encrypted payloads with encoded strings, and sometimes claimed code would run when it would not.

Why reverse engineering?

Most AI coding benchmarks begin with readable code and a clear task. Security teams often begin with neither. They get a compiled program, limited context, and one question: what does this actually do?

AgentRE measures whether an agent can turn that uncertainty into a defensible explanation. Agents recover behaviors, configurations, infrastructure, API chains, and execution details through tool use. Correct findings earn credit; unsupported claims are penalized against versioned ground truth.

Why AgentRE matters ↗

How it works

Agents receive an isolated binary and static-analysis tools. Recorded model configurations and the scoring version accompany each result.

  1. 01

    Present a binary without source

    A source-free, anonymized binary in an isolated workspace, with ordinary static-analysis tools and no internet access.

  2. 02

    Record the investigation

    Tool calls, evidence, time, coverage, failures, and final structured claims are captured for review.

  3. 03

    Score what can be proved

    Versioned ground truth rewards correct detail and penalizes unsupported claims. The same answer always receives the same score under the same scorer.

Calibration becomes the advantage

A broader model field ran the same Linux ladder. Gemini 3.1 Flash Lite led with a 0.5618 Main score and full 13/13 coverage. Fewer unsupported claims mattered more than deeper reasoning on this suite.

V1February 2026

Establishing the baseline

Thirteen synthetic Linux challenges established a source-free baseline with constrained tools and deterministic scoring. Completion was not the same as trust; every model scored zero on the bonus challenge.

Episodes

One episode is one complete attempt by one model on one binary, including its tool calls and final outcome. Twenty binaries × five attempts × five models = 500 episodes.

Overall

The average of all 20 binary scores. Each binary score averages five attempts. Main contributes 90% and Bonus 10%. Refusals and budget exits count as zero. All scores are out of 100.

Main

The average across 18 binaries from Levels 14–22. These binaries account for 90% of Overall.

Bonus

The average across the two Level 23 binaries. Together they account for 10% of Overall, the same weight as any other program’s two variants.

Valid answers

Answers that passed the required format checks. Valid does not mean correct. Each model had 100 attempts; the score measures what those answers recovered.

Answer quality

Average valid-answer scores within each answered binary, then average those binaries equally. Nonanswers are excluded here. Models answered different subsets, so compare this number alongside coverage.
